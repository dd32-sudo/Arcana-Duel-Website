# Arcana Duel · Promotional Website

A dark-fantasy themed promotional website for Arcana Duel, a two-player turn-based tarot card strategy game built with Unity 2D.

## Pages
- Homepage — Story lore, 7 battle card types, gameplay rules, 5 game scenes, 22 Major Arcana divination deck gallery
- Feedback Form — Player feedback with input validation and error handling

## Visual Style
Dark navy-gold aesthetic with glassmorphism UI, radial gradient backgrounds, and medieval-inspired typography.

## Built With
- HTML
- CSS
- JavaScript
